Phase 0 Test Infrastructure

Goal: Establish a test harness that catches regressions before any refactoring begins.

0.1 Fix Test Isolation

ProblemFix

47× set_datadir('.')Replace with tmp_path
198× tempfile.mktemp()Replace with tempfile.mkstemp() or tmp_path

Tests depend on execution orderEach test creates its own domain

0.2 Add Test Markers

Tag ~50 slowest tests with @pytest.mark.slow. This enables a fast feedback loop:

pytest -m "not slow"          # fast feedback (~5 min)
pytest -m slow                # full suite (~38 min)

0.3 Golden-Master Snapshots

Install pytest-regressions and create numerical snapshots for critical solver paths:

def test_evolve_bedslope(num_regression):
    domain = create_bedslope_domain(tmp_path)
    for _ in domain.evolve(yieldstep=0.1, finaltime=1.0):
        pass
    num_regression.check(
        {"stage": domain.quantities["stage"].centroid_values,
         "xmom": domain.quantities["xmomentum"].centroid_values},
        default_tolerance=dict(atol=1e-10, rtol=1e-10),
    )

Target: 8–12 golden-master tests covering evolve, distribute, extrapolate, and compute_fluxes.

Phase 3 Code Deduplication & Modular Structure

Goal: Reduce ~7,700 lines of duplication and establish separation of concerns.

3.1 Unify Quantity Kernels

Merge three near-identical files (quantity_ext.pyx, quantity_ext_openmp.pyx, quantity_ext2.pyx) into a single source with compile-time OpenMP toggle. OpenMP pragmas are no-ops when compiled without -fopenmp.

3.2 Consolidate Parallel Operator Wrappers

5 files in parallel/ thin-wrap their structures/ counterparts. Move MPI-awareness into base classes with a self.parallel flag.

3.3 Merge Duplicate Culvert Classes

Extract shared logic from Culvert_operator and Culvert_operator_Parallel into a base class. Parallel version overrides distribute() only.

3.4 Clean Up Utility Modules

Split system_tools.py (750 lines) into file_utils.py, env_utils.py, version_utils.py. Deduplicate numerical_tools.py vs scipy wrappers.

Deliverables

  • Single quantity extension source (serial + OpenMP from one .pyx)
  • Parallel operators consolidated (5 wrapper files removed)
  • Culvert classes deduplicated
  • Utility modules split and focused
  • All golden-master tests still pass

Rules for Fork Hygiene

#Rule
1Keep main in sync. Regularly merge upstream/main into origin/main.
2Rebase feature branches on main, not develop. Upstream develop is unstable.
3Submit upstream-worthy changes as separate PRs (dependency fixes, test isolation, linting).
4Never bulk-format files you're not changing. #1 source of merge conflicts.
5Monitor upstream develop. When PR #115 merges, rebase and resolve HIGH-risk conflicts.
6Coordinate with samcom12 on C/Cython. GPU fork touches the same quantity kernels.

Decisions Log

DecisionRationale
Rejected Mutation testing Poor ROI: can't mutate Cython, tolerance-based assertions kill most mutants, 50K+ mutants would take days
Deferred Property-based testing Valuable but not a prerequisite — defer to Phase 4
Adopted pytest-regressions Purpose-built for numpy array tolerance comparisons, baselines in VCS
Adopted diff-cover Enforces quality on new/changed code without massive backfill
Adopted Ruff Single tool replaces linter + formatter + import sorter, 10–100× faster
Adopted Incremental formatting Bulk reformatting creates merge conflicts with upstream and GPU fork
Adopted Upstream PRs for generic fixes Dependency fixes, test isolation, linting benefit the whole community
