Use pytest-regressions for 8–12 numerical snapshots covering evolve, distribute, extrapolate, compute_fluxes:

def test_evolve_bedslope(num_regression):
    domain = create_bedslope_domain(tmp_path)
    for _ in domain.evolve(yieldstep=0.1, finaltime=1.0):
        pass
    num_regression.check(
        {"stage": domain.quantities["stage"].centroid_values,
         "xmom": domain.quantities["xmomentum"].centroid_values},
        default_tolerance=dict(atol=1e-10, rtol=1e-10),

Phase 3 — Deduplication (Weeks 6–8)

3.1 Unify quantity kernels

Merge quantity_ext.pyx, quantity_ext_openmp.pyx, and quantity_ext2.pyx into one file. OpenMP pragmas are no-ops without -fopenmp, so a single source with a compile-time toggle works.

3.2 Consolidate parallel operator wrappers

5 files in parallel/ thin-wrap structures/ counterparts. Move MPI-awareness into base classes with self.parallel flag. Eliminates the conditional import block in __init__.py:253-264.

3.3 Merge culvert classes

Culvert_operator and Culvert_operator_Parallel share ~85% code. Extract base class, parallel subclass overrides distribute() only.

3.4 Split utility modules

system_tools.py (750 lines) → file_utils.py, env_utils.py, version_utils.py. Deduplicate numerical_tools.py vs scipy wrappers.

Done when:

  • Single quantity extension source (serial + OpenMP)
  • 5 parallel wrapper files removed
  • Culvert classes deduplicated
  • Utility modules split
  • All golden-master tests still pass

Decisions Log

DecisionRationale
Rejected Mutation testing Can't mutate Cython, tolerance-based assertions kill most mutants, 50K+ mutants would take days
Deferred Property-based testing Valuable but not prerequisite for refactoring — revisit in Phase 4
Adopted pytest-regressions Purpose-built for numpy array comparisons with tolerance, baselines stored in VCS
Adopted diff-cover Enforces coverage on changed lines only — no massive backfill needed
Adopted Ruff Replaces flake8 + black + isort in one tool, 10–100x faster
Adopted Incremental formatting Bulk reformat creates merge conflicts with upstream and GPU fork
Adopted Upstream PRs for generic fixes Dep fixes, test isolation, linting benefit the whole community
